# retrogame-mod-pok-dev

- **Repository**: [alesop95/retrogame-mod-pok-dev](https://github.com/alesop95/retrogame-mod-pok-dev)
- **Technologies**: Python, formati di salvataggio delle generazioni 1-3
- **Period**: 08/2026 - ongoing

Technical research, code and procedures for reading, verifying and transforming Pokémon data across consoles and generations, with the goal of completing a collection in Pokémon Home starting from owned cartridges and consoles. The repository is split into ten subprojects that move forward in parallel, from Nintendo 3DS modding and cartridge dumps to battery replacement, and from local wireless trading with the Nintendo Switch to recreating historical distributions and events.

The core technical part is a byte-level reference of the formats of the first three generations, covering box and party structures, name encodings, checksums, encryption and the Link Cable protocol, together with the Python library pokebridge, which reads and writes structures and saves of those generations and has byte-for-byte round-trip tests and a module that synthesizes the transfer of data from the third to the fourth generation. The case of a Pokémon Emerald save documents the repair of a corrupted inventory, with slot reassembly, recomputation of section checksums and verification of the write by reading it back. Catalogues and tables are generated by reproducible tools, and the most recent batches are generated and checked with the PKHeX.Core library.

A single source register states for each source what it documents and how reliable it is, and tells the sources actually read apart from those only catalogued. The project is active: by mid-September 2026 the checklist towards Home stood at 685 entries out of 1025 in the national Pokédex. Personal saves and dumps stay out of git.
