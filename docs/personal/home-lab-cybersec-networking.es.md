# home-lab-cybersec-networking

- **Repositorio**: [alesop95/home-lab-cybersec-networking](https://github.com/alesop95/home-lab-cybersec-networking)
- **Tecnologías**: OPNsense, VLAN 802.1Q, TrueNAS (previsto)
- **Periodo**: 01/2026 - en curso

Diseño documentado de una red doméstica segmentada: firewall dedicado OPNsense, VLAN, monitorización de seguridad y servicios self-hosted, sobre una línea de fibra cuyo módem no se puede sustituir ni poner en modo bridge. Por eso el firewall está detrás del módem, con un doble NAT aceptado como restricción. El repositorio contiene la documentación, anonimizada y verificada por un control automático, y las herramientas que la producen.

Estado: en curso. El firewall tiene el sistema operativo instalado y la configuración de red está todavía por hacer; el switch y los puntos de acceso no se han comprado. Está en curso el montaje de un NAS obtenido de cuatro ordenadores de sobremesa dados de baja, con un pool de datos en discos recuperados.
