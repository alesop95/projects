# home-lab-cybersec-networking

- **Repository**: [alesop95/home-lab-cybersec-networking](https://github.com/alesop95/home-lab-cybersec-networking)
- **Technologies**: OPNsense, VLAN 802.1Q, TrueNAS (previsto)
- **Period**: 01/2026 - ongoing

Documented design of a segmented home network: a dedicated OPNsense firewall, VLANs, security monitoring and self-hosted services, on a fiber line whose modem can be neither replaced nor put in bridge mode. The firewall therefore sits behind the modem, with double NAT accepted as a constraint. The repository contains the documentation, anonymized and checked by an automated test, and the tools that produce it.

Status: in progress. The firewall has its operating system installed and the network configuration is still to be done; switch and access points have not been bought. A NAS built from four decommissioned desktops is being assembled, with a data pool on reused disks.
