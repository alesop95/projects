# sony-xperia-1-III-customization

- **Repository**: [alesop95/sony-xperia-1-III-customization](https://github.com/alesop95/sony-xperia-1-III-customization)
- **Technologies**: LineageOS 22.2, Android, Python
- **Period**: 07/2026, paused

A documentation and tooling project for customizing a Sony Xperia 1 III (codename pdx215) with LineageOS 22.2, organized into runbooks covering software setup, audio, photo and video and gaming, along with a small collection of scripts. The tooling includes PowerShell and shell scripts to preflight-check the phone and batch-install APKs over ADB, a Magisk module skeleton, and some Python audio-analysis scripts (spectral audit, benchmark calculation, comparison of tracks against reference masters) to evaluate the quality of high-resolution music files on the device's audio path.

A separate script converts a large source .docx, kept locally outside version control, into the Markdown documentation tracked in the repository. The value is in the notes, the checklists and the small verification scripts.
