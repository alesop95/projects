# Channel Estimation and Equalization for MIMO Systems

**Periodo**: 2017

**Rol**: autor

## Qué se hizo

Proyecto de procesamiento estadístico de señales: un esquema matricial para la estimación y la ecualización del canal en sistemas MIMO[^1]. El [PDF completo](https://drive.proton.me/urls/X17ZP29GR4#zwkFN_Cx9ipD) documenta el esquema y los resultados.

[^1]: *MIMO*, Multiple Input, Multiple Output - sistema de transmisión con varias antenas tanto en el transmisor como en el receptor.
