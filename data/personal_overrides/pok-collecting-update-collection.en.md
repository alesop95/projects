A price-tracking companion for a personal Pokémon TCG collection kept in an Excel workbook. The script treats the spreadsheet as the source of truth: it reads the owned cards directly from the workbook through COM automation (xlwings), fetches current market prices from the CardTrader v2 REST API, and writes a lookup cache with ready-to-paste formulas, so that Excel shows up-to-date prices through XLOOKUP-style lookups. A SQLite database keeps an append-only price history, so trends are not lost between runs.

It was built after Cardmarket closed its public pricing API, around 2024 according to the project's documentation, leaving CardTrader as the data source. A discovery script fuzzy-matches the workbook's sheet names against the API's expansion catalogue, because sheet names do not match the API identifiers. The lookup formulas are generated in Italian Excel syntax, with semicolons as separators and localized function names.
