Bilingual personal blog (English and Italian), hand-built on Next.js 16, React 19 and Tailwind 4, exported as a static site and published to GitHub Pages with GitHub Actions at [alesop95.github.io/blog](https://alesop95.github.io/blog). Each post is an MDX file in `content/posts/{en,it}/`; the two translations are linked by an `articleId` frontmatter field and have their own per-language URLs.

At build time the site generates Open Graph images (Satori) and the search index (Pagefind); it uses KaTeX for math, Shiki for code and abcjs for sheet music, and has interactive components for harmony and equalization, Giscus comments, a Buttondown newsletter, `/uses` and `/now` pages and per-topic pages. Verification combines TypeScript, Biome, Vitest, Playwright with axe-core accessibility checks and Lighthouse CI. Design decisions are recorded as ADRs, including publishing as a project site instead of on a custom domain.
