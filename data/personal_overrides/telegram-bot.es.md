Un bot de Telegram construido sobre python-telegram-bot con dos backends de persistencia, SQLite para las ejecuciones locales y PostgreSQL para el despliegue en la nube, elegidos mediante puntos de entrada separados (`main.py` y `main_cloud.py`) en lugar de un interruptor en tiempo de ejecución. Ofrece mensajes personalizados con formato y botones inline, plantillas reutilizables, cinco temas de chat seleccionables, ajustes por usuario (notificaciones, idioma, zona horaria) y estadísticas de uso personales y para el administrador, con el objetivo de replicar una parte de las funciones de personalización de Telegram Premium sin suscripción. Incluye un pequeño endpoint de health check, archivos Docker y docker-compose, configuraciones de despliegue para Railway y Render y un workflow de GitHub Actions.

La programación de mensajes aparece en el propio bot como en desarrollo, por lo que el conjunto de funciones del README está activo solo en parte. Los handlers, el acceso a la base de datos y la configuración están separados.
