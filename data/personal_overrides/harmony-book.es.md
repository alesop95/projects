Cadena de publicación de un libro de armonía: el repositorio versiona el método tipográfico y la compilación, mientras que el texto del libro queda fuera de git. La composición usa LuaLaTeX con la clase memoir, LilyPond incorporado con lilypond-book para los ejemplos musicales, biblatex y biber para la bibliografía, imakeidx y glossaries para índice y glosario. El entorno TeX es una instalación local de TinyTeX descrita por un manifiesto de paquetes, reproducible en Windows y Linux.

El manuscrito (capítulos, ejemplos, bibliografía) está en una carpeta excluida de git porque está destinado a la venta; un documento de ejemplo demuestra que la cadena funciona. El repositorio contiene también herramientas en Python para la teoría musical usada en el libro, como el cálculo del contenido de tritonos de las escalas y la derivación de las dominantes secundarias, y una base de conocimiento sobre las fuentes consultadas.
