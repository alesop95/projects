Blog personal bilingüe (inglés e italiano), construido a mano sobre Next.js 16, React 19 y Tailwind 4, exportado como sitio estático y publicado en GitHub Pages con GitHub Actions en [alesop95.github.io/blog](https://alesop95.github.io/blog). Cada artículo es un archivo MDX en `content/posts/{en,it}/`; las dos traducciones se vinculan con un campo `articleId` en el frontmatter y tienen URL propias por idioma.

En tiempo de build el sitio genera las imágenes Open Graph (Satori) y el índice de búsqueda (Pagefind); usa KaTeX para las matemáticas, Shiki para el código y abcjs para las partituras, y tiene componentes interactivos de armonía y ecualización, comentarios Giscus, newsletter Buttondown, las páginas `/uses` y `/now` y páginas por tema. La verificación combina TypeScript, Biome, Vitest, Playwright con controles de accesibilidad axe-core y Lighthouse CI. Las decisiones de diseño se registran como ADR, entre ellas la publicación como project site en lugar de en un dominio propio.
