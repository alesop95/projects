A notes repository for a home recording and mixing studio. The technical content so far covers the work machine, a repurposed desktop running Ubuntu Studio 26.04: the clean install, the low-latency setup obtained from the generic kernel with the `preempt=full` and `threadirqs` boot parameters, the PipeWire audio chain with the procedure to verify it, the Wine compatibility layer for Windows programs, and the reinstall and backup procedure with Veeam Agent for Linux. This block is a synchronized copy from the sibling project diy-2way-monitors-home, which uses the same machine.

The project's own decision is still open: choosing an audio interface with more inputs for multitrack recording, with the criteria fixed before comparing models, starting from the number of simultaneous inputs and USB audio class compliance, which on Linux avoids proprietary drivers and configuration software. There is no recording signal chain, DAW project, gear list or mixing notes yet.
