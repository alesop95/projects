Una herramienta en Node.js y TypeScript que genera propuestas de equipos Pokémon competitivos para el formato Pokémon Champions, a partir del roster disponible en una temporada. Razona sobre la composición del equipo con etiquetado y puntuación deterministas, sin simular combates: los roles se deducen de estadísticas, habilidades y movepools, los candidatos se puntúan por sinergia y cobertura de tipos frente a los metadatos actuales, y la salida da para cada equipo una justificación, las debilidades previstas y los counters probables. Los datos del juego, la tabla de tipos y el cálculo de daño proceden del ecosistema de código abierto de Pokémon Showdown (`@pkmn/dex`, `@smogon/calc`), y las reglas del formato del mod Champions mantenido por la comunidad de Showdown.

La lógica del juego está separada de los datos de temporada, de modo que una nueva temporada se admite actualizando los archivos JSON y YAML sin tocar el motor. El motor de etiquetado y generación funciona desde la CLI y, para el uso local, detrás de un servidor Fastify; un segundo nivel opcional enriquece la justificación mediante la API de Claude cuando hay una clave configurada, y si no se mantiene el texto determinista. Una versión web estática construida con Vite ejecuta el motor por completo en el navegador, guarda el historial de equipos en IndexedDB y está preparada para el alojamiento en GitHub Pages. La puntuación con el cálculo de daño refinado está aún por completar, y un modo de construcción manual del equipo, con sugerencias del motor para las casillas vacías, está diseñado pero no realizado.
